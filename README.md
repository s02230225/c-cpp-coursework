# Практикум C и C++

**C · C++ · UNIX**

Подборка решений университетского практикума: структуры данных, обработка ввода, файловые и процессные средства UNIX, задачи на C и C++. Исходная иерархия тем и домашних работ помогает сопоставлять программу с условием.

Открой README конкретного задания в Homeworks или Tasks и собери его отдельно: в разных упражнениях есть собственные main и требования к языку.

```bash
cc -std=c11 -Wall -Wextra path/to/solution.c -o solution
c++ -std=c++17 -Wall -Wextra path/to/solution.cpp -o solution
```

Каждое задание собирается в отдельную программу. Для упражнений с системными вызовами требуется Linux/POSIX. В подкаталогах находятся исходники, заголовки и условия заданий.
