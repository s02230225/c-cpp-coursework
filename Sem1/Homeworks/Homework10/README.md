# Сигналы, процессы и конвейеры

Упражнения по обработке сигналов, запуску команд, перенаправлениям и конвейерам POSIX.

- `costable.c`, `prime.c`, `primediv.c` — вычислительные примеры с обработкой сигналов.
- `shellcmd0.c`, `shellcmd1.c`, `shellcmd2.c` — запуск команд и организация конвейеров.

Каждая программа собирается отдельно. Требуется Linux/POSIX и C-компилятор.
