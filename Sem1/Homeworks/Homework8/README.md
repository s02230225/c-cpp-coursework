# Процессы и файловые дескрипторы

Примеры работы с процессами POSIX: создание дочернего процесса, запуск команд,
ожидание завершения и перенаправление ввода-вывода через файловые дескрипторы.

- `n2_dadandson.c`, `r8_19.c`, `r8_20.c` — создание и взаимодействие процессов.
- `n3_macro.c`, `n6_seq.c`, `n7_duplicate_all.c`, `n8_duplicate.c` — отдельные упражнения практикума.
- `system.c` — запуск команды через оболочку.

Каждая программа собирается отдельно. Требуется Linux/POSIX и C-компилятор.
