#### double_char

Программа удваивает каждый символ (байт) в файле используя низкоуровневый ввод/вывод: считает размер файла n, начиная с n-1 и до 0: пишет nый символ на n+n и n+n+1 места.

---

#### double_char_high_inout

Программа удваивает каждый символ (байт) в файле используя высокоуровневый ввод/вывод: считает размер файла n, начиная с n-1 и до 0: пишет nый символ на n+n и n+n+1 места.

#### double_string

Программа удваивает каждую строку (последовательность байт между двумя '\n') в файле. Используется низкоуровневый ввод/вывод.

---

#### double_string_high_inout

Программа удваивает каждую строку (последовательность байт между двумя '\n') в файле. Используется высокоуровневый ввод/вывод.

#### number_8

Решает задачу, звучащую так:
Программе передаются два аргумента командной строки: имя файла для обработки (FILE), затем число элементов для обработки (N). Файл для обработки — это бинарный файл, содержащий вещественные числа двойной точности. Размер файла всегда кратен размеру одного числа. Если файл не содержит чисел или содержит только одно число, он не изменяется. Если файл содержит более одного числа, первое число не изменяется, а i-е число в файле после обработки вычисляется по формуле out[i] = in[i] - out[i - 1], где out – содержимое файла после обработки, а in – содержимое файла до обработки. Число N определяет максимальное количество обрабатываемых чисел, то есть если в файле более N чисел, то обрабатываются первые N чисел, а остальные не изменяются. in[0] учитывается в числе N. Таким образом, при N < 1 входной файл вообще не изменяется.

#### size_of_files

Программа выводит суммарный размер файлов в байтах, указанных в качестве аргументов программы.

---

#### sum_from_arg

Выводит 2 суммы составленных из чисел введённых через аргумент: чисел >=0 и чисел <0.
