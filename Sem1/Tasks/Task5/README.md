#### tree

Макросы

FREE_LIST(ls): Освобождает память, занятую списком аргументов.


Структура данных
Основной структурой данных является tree, представляющая узел дерева команд. Каждый узел содержит следующие поля:

argv: массив строк, представляющий аргументы команды.
infile: строка, представляющая имя входного файла.
outfile: строка, представляющая имя выходного файла.
append: флаг, указывающий, необходимо ли добавлять вывод к файлу.
backgrnd: флаг, указывающий, должна ли команда выполняться в фоновом режиме.
psubcmd: указатель на подкоманду (если есть).
pipe: указатель на следующую команду в пайпе (если есть).
next: указатель на следующую команду в цепочке (если есть).
type: тип команды (NXT, OR, AND).


Функции

void make_shift(int n)
Создает отступ в выводе. Каждые 5 отступов выводит символ |.

void print_argv(char **p, int shift)
Печатает аргументы командной строки с заданным отступом.

int print_tree(tree t, int shift)
Рекурсивно печатает дерево команд, отображая все узлы и их параметры. Печатает аргументы, входные и выходные файлы, флаги фона и добавления, а также тип команды.

tree maketree()
Создает новый узел дерева, инициализируя все его поля значениями по умолчанию.

tree simplecommand(list *ls)
Обрабатывает простую команду, извлекая аргументы и модифицируя входные/выходные файлы.

tree conveyer(list *ls)
Обрабатывает команды в пайпе, создавая соответствующие узлы и связывая их.

tree andor(list *ls)
Обрабатывает логические операторы (AND, OR), создавая связи между узлами дерева.

tree nexttree(list *ls)
Строит дерево следующей команды, обрабатывая следующее поддерево.

void modifinout(tree t, list *ls)
Модифицирует входные и выходные файлы для узла, извлекая имена файлов из списка.

tree buildtree(list *ls)
Строит полное дерево команд, обрабатывая все операторы и связи.

tree buildsubshell(tree t1, list *ls)
Строит подкоманду, если встречена закрывающая скобка.

void delete_tree(tree *t)
Рекурсивно освобождает память, занимаемую деревом команд.

#### Shell

Программа реализует простую командную оболочку (shell), которая позволяет пользователю вводить команды, обрабатывать их и выполнять. Программа поддерживает работу с файлами, обработку сигналов и управление процессами.

Основные функции
Обработка сигналов: Программа обрабатывает сигнал SIGINT (обычно вызывается при нажатии Ctrl+C), что позволяет пользователю прерывать выполнение текущей команды и вернуться к вводу новых команд.

Работа с файлами: Если при запуске программы передан один аргумент, программа открывает файл и перенаправляет стандартный ввод на этот файл.

Командный ввод и выполнение: Программа запрашивает ввод команд, создает список команд, строит дерево команд и выполняет их.

Структура кода
#include "isword.h": Заголовочный файл, содержащий функции для работы со словами и командами.
#include "list.h": Заголовочный файл, содержащий функции для работы со связанными списками.
#include "tree.h": Заголовочный файл, содержащий функции для работы с деревьями.
#include "shlfunc.h": Заголовочный файл, содержащий функции, специфичные для оболочки (например, выполнение команд).

Переменные
jmp_buf begin и jmp_buf sexit: Используются для возврата в начало программы и выхода из программы соответственно.
list ls: Список команд, введенных пользователем.
tree t1: Дерево, представляющее структуру команд.
list qur: Временный указатель на список команд.
int endofshellint: Переменная для отслеживания состояния завершения оболочки.
int stat: Переменная для хранения статуса завершения дочерних процессов.
int ansrec: Переменная для хранения глубины рекурсии pip.

Завершение работы
Программа завершает свою работу, когда пользователь вводит команду завершения оболочки или при возникновении ошибки. При этом происходит очистка выделенной памяти и завершение всех дочерних процессов.
