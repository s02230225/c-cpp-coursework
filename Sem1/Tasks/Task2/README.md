#### task2_5

max_len_word определяет максимальный размер одного слова, используется в буфере при вводе.

Структура nod (далее так же узел) состоит из указателя на слово и указателя на следующий элемент.

Функция `nod* newnod(char* str, nod* prevnod)` получает на вход указалель на строку (в буфере) и необязательный параметр указатель на узел prevnod - указатель на предыдущий элемент (NULL если не используется), функция выделяет память под новый узел, выделяет память ровно под размер слова и записывает указатель на слово в узел, и если дан prevnod подсоединяет новый узел к нему. Возвращет указатель на новый узел.

Процедура `void delnod(nod* thisnod, nod* prevnod)` получает указатель на удаляемый узел и необязательный параметр указатель на узел prevnod, функция если указал доп. параметр делает так, что следующий за prevnod теперь следующий за удаляемым узлом, освобождает память слова удаляемого узла и память самого удаляемого узла.

Процедура `printfnod(nod* firstnod)` получает указатель на первый элемент, печатает все слова узлов пока не встретит узел, у которого нет слудующего.

Функция `nod* delcopynod(nod* firstnod, nod* lastnod)` получает указатели на первый и последний узлы. Возвращает указатель на новый первый узел (необходимо при вызове функции firstnod=delcopynod(...)). Пока слово первого узла совпадает с словом последнего узла, удаляет первый узел, первым становится следующий за тем первым. Если после этого первый совпадает с последним, выход из функции. Рассматриваются узлы от 2го до предпоследнего: проверяется совпадение слова слудующего за ним узла с словом последнего, если совпадают - узел удаляется (отдельно условие для предпоследнего узла, тк алгорит предполагает использование ссылки слудующего следующего узла, которого нет у предпоследнего).

Процедура `void freeallnod(nod* firstnod)` удаляет все узлы начиная с данного firstnod.

В main в буфер по очереди вводятся слова, с ними создаётся последовательность узла, потом вызовы delcopynod, printfnod  и freeallnod.

#### task2_6

Uint = unsigned int.

Структура узел - int и две ссылки на два узла less и more (далее в дереве поиска слева элемент меньший, справа - больший).

`nod* newnod(Uint val)` выделяет память под один узел, записывает в него значение, возвращает указатель на узел.

`nod* createnod(Uint val, nod* firstn)` итерационно ищет место для узла с данным значением, если такой есть - ничего, если такого нет - создает с помощью newnod, возвращает указатель на корень, тк при создании первого узла указатель на первый узел создается.

`void changebranch(nod* thisn, nod* prevn)` процедура - часть процедуры удаление вершины из дерева поиска, результат - ветвь элементов справа от thisn (все больше чем thisn) прикрепляет вслед за максимальным элементом слева от thisn (все меньше thisn); всю ветвь, которая теперь слева от thisn прикрепляет к элементу предшествующиему thisn (те на место thisn).

`nod* deliten(Uint val, nod* firstn)` процедура удаления элемента из дерева, проверяет дерево на пустоту, проверяет удаление корня дерева (а значит и изменение корня дерева), проверяет наличие элемента в дереве, если есть - изменение дерева changebranch и освобождение памяти; возвращает указатель на корень, тк корень изменяется при своём удалении.

`int searchn(Uint val, nod* firstn)` итерационно ищет значение в дереве, если нашло возвращает 1, если нет - 0.

`void freealln(nod* thisnod)` рекуриентно освобождает память всего дерева.

`void printfn(nod* thisnod)` дополнительная процедура, выводит граф в строку с символами L R U (L-left, R-Right, U-Up) - порядок обхода дерева в глубину.

`main()` пока не конец файла может добавлять вершины в граф поиска, удалять их из него, проверять наличие элемента в графе, в конце освобождает всю память.
