## Task4

#### ls

Реализует ls с [-l, -R, -g]. Содержит функции printFileInfo, выводящую статистику о правах доступа, владельце, размере и имени файла в отдельной строке; listDirectory вводит содержимое директории (данной); listDirectoryRecursive выводит содержимое директории и всех в неё входящих.

---

#### echo

Реализует echo с [-n, -e]. Содержит функции print_help, выводящую возможные флаги; interpret_and_print, анализирующую спецсимволы и иначе выводящую символ.

---

#### mv

Реализует mv. Содержит функции move, перемещающую файл (переименовыванием); copy_permissions, которая пытается скопировать права.

---

#### pwd

Реализует pwd. Содержит функцию mypwd, корорая выводит полное имя текущей директории.

---

#### wc

Реализует wc. Содержит функцию count_file, которая проходом по файлу собирает статистику о символах, словах, строках.

---

#### cat

Реализует wc. Содержит функцию print_file, выписывающую содержимое очередного файла.

---
