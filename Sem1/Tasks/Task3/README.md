#### task 

Содержит всё задание одним файлом.

Работа: Считывает сторки из stdin, строка разделяется на спецслова: ```| || & && ; > >> < ( )``` и слова, состоящие из строчных и заглавных букв, цифр, символов ```$ _ / .```. Слова заносятся в "список строк". Выводится количество слов в строчке, выводятся все слова, слова сортируются в лексикографическом порядке и выводятся, для следующей строки список очищается.

В программе описываются:

процедуры null_list, nullbuf, nullrb обнуляющие соответствующие объекты;

функции isspec, symset, iscorr для определения типа символа;

процедура clearlist для освобождения памяти;

процедуры printlist, outst для вывода результатов в stdout;

процедура err сообщает об ошибке и правильно завершает программу;

функция getsym считывает определённое количество в свой буфер за раз и возвращает символы по одному;

процедура addsym формирует очередное слово в буфере, если требуется, то расширяет буфер; 

процедура addword добавляет слово из буфера в список слов, завершая его '\0', увеличивая размер списка на 1;

процедура termlist завершает список, добавляя NULL в последнюю позицию и обрезает память до точного размера.

В main инициализируются необходимые объекты, и пока не конец файла: анализируется очередной считанный символ, в зависимости от символа вызывается последовательность функций, добавляющая, выводящая или обнуляющая список слов. В конце вся память освобождается.

---

#### module, maintask3, Makefile

module.h - вынесенные структура, описания процедур и функций. maintask3 - main часть программы с описание процедур и функций, Makefile собирает программу из module и maintask3, создавая программу task3, аналогичную task.
