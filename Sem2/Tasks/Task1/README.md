#### server

Обеспечивает чат между клиентами. Получает сообщения или команды от пользователей, пересылает сообщения, выполняет 3 команды: \quit: выход из чата; \users: получить список всех подключенных пользователей; \info: узнать пользователя с максимальным количеством отправленных сообщений.

---

#### client

Отправляет сообщение на сервер, при команде quit отправляет информацию о завершении серверу и перестает слать сообщения, получает сообщения от сервера и выводит их на экран.
